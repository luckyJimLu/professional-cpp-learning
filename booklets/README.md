## 快速查找

- 输入函数名、中文术语或符号，例如 `malloc`、`字符串`、`%zu`。
- 多个词按“全部包含”匹配，例如 `realloc 失败`；忽略大小写，符号按字面匹配；直接命中条目或关键词的结果优先于仅在正文出现的结果。
- 全册 11 章、77 个条目默认连续显示在一个页面。桌面左侧目录、手机吸顶的原生章节导航均滚动定位，不隐藏其他章节；目录随阅读位置高亮。
- 搜索临时展示匹配结果；清除搜索恢复全册。搜索时选择目录章节，也会恢复全册并跳到该章。选择“册首与搜索”可返回顶部。
- 搜索、分册切换和返回按钮随阅读保持可用；手机同时提供章节选择，横屏减少工具栏占用。
- 多个搜索结果先显示可滚动的条目索引，点选后定位完整正文；“返回搜索结果”可回到索引。
- 页面内按 `/` 聚焦搜索，Enter 跳到结果概览，Esc 清除（输入法组字时不触发）。Ctrl/Cmd+K 仍为全站代码搜索。
- 点击条目标题取得可分享定位网址；查询 `bq`、章节位置 `category`、条目 `entry` 保留在 URL，刷新和浏览器历史可恢复。
- 代码复制复用站点共享控件；下载 Markdown 可离线查阅。

额外强调了：格式说明与参数类型、字符串容量与终止符、整数溢出、数组退化、借用有效期、分配乘积溢出、realloc 失败、释放责任、字符分类的参数范围、文件部分读取，以及 volatile 不提供线程同步。

## C17 与 C++ 主机自测

在具备 GCC 的主机仓库根目录执行：

```bash
npm run check:booklets
```

或直接编译自测：

```bash
gcc -std=c17 -Wall -Wextra -Wconversion -Wpedantic -Werror booklets/examples/c17-reference.c -o /tmp/c17-reference
/tmp/c17-reference
```

预期输出：`C17 cheatsheet checks passed`。自测需要启用断言，不能使用 `-DNDEBUG`；仅写临时文件，不覆盖用户文件。自测覆盖格式输入、边界解析、数组、排序、内存、文件 I/O，以及泛型选择、可变参数、柔性数组、原子操作等选定行为，不证明任意硬件或实时属性。

`tools/check-booklets.py` 检查分类／条目 ID、关键词与代码围栏，校验 29 个标准头文件与 44 个关键字，并编译运行两个完整内联程序和所有独立自测。其余局部片段不单独编译，也不自动送入 C++ Lab。Web Build 与 Pages 工作流已接入该检查。

## 维护

内容源分别为 `booklets/c.md` 与 `booklets/cpp.md`；`src/lib/booklets.ts` 解析分类、稳定条目 ID、关键词与正文。每册的同一个 Markdown 同时服务网页和下载，不另维护一套复制的页面正文。

保留 `<!-- category: id -->`、`<!-- entry: id -->` 标记和每条的 `关键词：` 行，避免破坏分享链接。新增标准或平台接口时标明适用范围，正常与失败路径均可解释，再运行内容检查与 `tests/booklets.spec.ts`。

C++ 完整自测位于 `examples/cpp20-reference.cpp` 和 `examples/cpp23-reference.cpp`；使用 `npm run check:booklets` 在临时目录中运行。需要同时提供 C17 与 C++23 可用的主机编译器，可通过 CC/CXX 指定；局部示例不声称能独立编译。
