# 全系列统一风格规范（Style Guide）

> 本文件定义整个 C++ 系列课程的视觉与语言基线。
> 生成任何一页提示词时，必须把下方「风格锚点块」**一字不改**地嵌入。
> 如需调整系列风格，只改这里，所有课程同步生效。

---

## 风格锚点块（原样复制进每一页提示词）

```
【系列风格锚点 · 必须严格遵守】
- 系列名称：Professional C++ —— 从语言机制到软件设计
- 整体气质：工程师向、克制、专业，类似顶级技术大会（CppCon / Meeting C++）演讲风格；拒绝卡通、拒绝营销腔。
- 配色：深色背景 #0F172A（深海军蓝）；主文字 #E2E8F0；强调色 #38BDF8（青蓝，用于关键词与标题下划线）；
  正面/推荐 #22C55E（绿）；反面/警告 #EF4444（红）；辅助高亮 #F59E0B（琥珀，仅用于金句）。
- 字体：标题用无衬线粗体；正文用无衬线常规体；代码统一用等宽字体（JetBrains Mono 风格），深色代码底板 + 语法高亮。
- 版式：16:9；左上角固定小字页眉「第 X 课 · <课程短标题>」；右下角固定页码样式「PPT N」。
  标题居左，标题下方一条 #38BDF8 细横线。正文要点 ≤ 5 条，每条 ≤ 25 字。
- 图示：扁平化线框图、分层图、对比表；线条细、圆角矩形；不使用照片和 3D 效果。
- 代码约定：❌ 标记反例（红色左边框），✅ 标记推荐写法（绿色左边框）；左右或上下对照排列。
- 金句：单独一个琥珀色引用框，附作者名，英文原文 + 中文译文。
- 术语：首次出现写作"中文（English）"，之后保持一致。
- 语言：幻灯片正文使用简体中文，C++ 关键字、类型名、标准库名保持英文原样。
```

## 页面类型与推荐版式

| 页面类型 | 适用场景 | 推荐版式 |
|---|---|---|
| 开篇/概念页 | 课程开场、核心定义 | 左侧大图示（60%）+ 右侧要点（40%），底部金句框 |
| 模型/分层页 | 金字塔、层次结构、分类 | 居中分层图，两侧标注轴线或虚线框 |
| 对比页 | 反例 vs 正例、旧 vs 新 | 左右双栏，❌ 左 / ✅ 右 |
| 代码页 | 机制演示 | 上方一句结论，下方代码块，右侧 2–3 个标注气泡 |
| 总结页 | 本课收尾 | 3–4 个卡片 + "下节预告" 条带 |

## 语言风格

- 标题：短句式结论，而非名词堆砌（✅「所有权必须写进类型」 / ❌「所有权相关介绍」）。
- 正文：关键词化，不写完整长句；完整解释放进演讲者备注。
- 演讲者备注：口语化、有画面感，保留大纲中的痛点故事与比喻。

## 衔接规范

- 每页底部可放一行浅色小字「下一页 → <启下问题>」，形成连续叙事。
- 每课第一页必须有一句"上节回顾"（第 1 课则写"系列开篇"）。
- 每课最后一页必须有"下节预告"。
