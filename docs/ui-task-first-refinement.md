# UI 任务流程优化 · 2026-10-20

保留工程蓝、白底文档与深色代码区，沿“找内容 → 阅读 → 实验 → 观察 → 复盘”优化。

| 范围 | 最终行为 |
| --- | --- |
| 手机 Lab | 任务、提示和重置共用折叠区；保留外部源码状态；共享工具栏只有一个“运行代码”。390×844 下代码起点从约 814px 提前至约 416px |
| 内存工作台 | 编译和回放工具栏独立于源码／输出面板，输出页可直接播放、暂停、后退、单步及重置；无轨迹时明确使用“近似推演” |
| 运行语义 | Lab 使用品牌蓝，RTOS 使用其既有青色；错误保留独立错误语义 |
| 课程 | 周摘要显示已有章节主题，标记当前周并提供锚点跳转；完整标题正常换行 |
| 专题 | Markdown 可定义短摘要；缺省使用完整介绍句，不按固定字符数截断；常用模块补充内容摘要 |
| 搜索 | 课程／文章标题优先，路径和行号保留为次级信息；保留单一显式清除按钮，清除取消尚未提交的搜索 |
| 首页 | 有有效本地访问记录时显示“继续阅读”，否则使用计划／最新课程；明确阅读不代表完成 |
| 复盘 | 待复习列表先于历史记录，手机概览缩小；不把仓库基线变成个人掌握度 |
| 阅读 | 压缩手机八阶段导航留白，保留全部阶段；规范页目录直接读取共享渲染器的章节 ID；课程阶段高亮按章节位置更新，避免长章节无法达到交叉比例门槛 |

## 设计契约校对

| 原规则／发现 | 处理 |
| --- | --- |
| 手机需保留工作台操作；原工具栏位于被隐藏的源码面板内 | 修复组件归属：同一个工具栏移到两个面板之外，没有新增第二套状态／处理函数 |
| 运行模拟使用了危险色 | 使用 RTOS 既有 `--rtos-cyan`；Lab 使用既有 `--blue`，不新增配色系统 |
| 课程来自 Markdown | 周主题、搜索标题和专题摘要均来自现有内容／元数据 |
| 阅读不代表掌握 | 上次阅读保存为独立导航记录，不调用阶段完成逻辑 |
