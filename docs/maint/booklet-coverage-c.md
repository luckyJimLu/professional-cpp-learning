## 必须分清的规则

- 优先级和结合方向决定分组，不等于求值顺序。
- 无符号回绕不是有符号溢出的处理方式；运算前检查范围。
- C17 普通字符常量类型是 int，字符串字面量虽不是 const 数组，也不能修改。
- 指针非空不保证有效；正确对齐也不自动满足有效类型与生命周期要求。
- printf 与 scanf 的类型要求不同；可变参数提升不等于 scanf 的目标指针也会提升。
- 非零 errno 不等于本次调用失败；先按具体函数约定检查返回值。
- restrict、union、volatile 不直接套用 C++ 的规则或线程安全结论。
- C17 的线程、原子和复数支持具有实现条件；裸机和 POSIX 不自动等于宿主 C17。
