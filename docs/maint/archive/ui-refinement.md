# 全站 UI 定向优化记录

本轮以现有 Professional C++ 学习工作流为基线，使用 Product Design Audit 与
Frontend Design / Frontend Design Premium 的审计、共享组件和回归方法。
保留蓝白文档风格、Markdown 内容源及已有的编译／模拟链路。

## 审计与处理

| 步骤 | 页面与任务 | 发现的问题 | 本轮处理 |
| --- | --- | --- | --- |
| 1 | 学习指南 → 进入学习 | 桌面主学习按钮被隐藏，缺少实验与专题入口 | 恢复双端主入口，展示最新课程与三个学习方向 |
| 2 | 课程 → 查找课例 | 手机长标题截断，目录从第一周铺满，检索状态不持久 | 周目录折叠、当前周默认展开；完整标题换行；URL 保存搜索和目录模式 |
| 3 | 课程阅读 → 阶段操作 | 手机八阶段挤在一排，复习按钮缺少操作反馈 | 保留八阶段，改为四列两行；加入复习后明确反馈；尊重减少动态效果设置 |
| 4 | 专题 → 浏览与阅读 | 已有独立目录和阅读布局，需要与全站导航保持一致 | 保留目录分层、阅读位置与桌面固定目录，统一页头与搜索入口 |
| 5 | 实验 → 源码与运行 | 大段说明推远工作区；窄屏默认输出隐藏了源码运行按钮 | 折叠说明和清单，增加工作区快捷入口及共享运行操作；默认源码，运行后切换输出 |
| 6 | 编码规范 → 阅读 | 中英文页标题与文档标题重复争抢层级 | 中文页面入口；共享 Markdown 以嵌入文档模式降低正文标题层级；限制阅读宽度 |
| 7 | 复盘 → 回到课程 | 卡片仅展示信息，空清单使用警告色，记录容易被理解成测评结果 | 检查点与知识点均可返回课程；中性空态；区分仓库基线和掌握程度 |
| 8 | 搜索 → 输入与恢复 | 空白页只有输入框，缺少搜索范围说明 | 增加统一页头、示例词和范围说明，保留 IME、清空焦点与 URL 状态 |
| 9 | 内存可视化 → 观察与控制 | 手机控件偏小，布局切换按钮与暗色工作区不一致 | 增加触控高度，统一切换按钮风格；保留预置、近似和编译事件的区别 |
| 10 | RTOS → 回放与配置 | 手机隐藏速度、快照和配置／导出；详情标签缺键盘导航 | 保留完整移动工具栏；配置原生非模态折叠；详情标签支持方向键、Home、End |

## 跨页面行为

- `Shell.tsx` 是全站导航的唯一 owner：页头当前页面、搜索、手机抽屉焦点循环、Escape 和返回桌面时释放背景。
- `PageHeader.tsx` 统一标识、标题、说明；`product-ui.css` 管理跨页面结构，继续使用 `styles.css` 的语义色与字体。
- `Markdown.tsx` 继续负责正文、表格和标题；嵌入文档不再额外产生页面一级标题。
- `CodeBlock.tsx` 仅在剪贴板写入成功后显示成功，失败时提供重试与手动复制提示。
- 查看页面、打开 RTOS 或生成近似内存轨迹不作为完成实验的证据。

## 验证

- 桌面 1440px、手机 390px：10 个主要页面的前后截图和页面错误／溢出检查。
- 320px、768px、1440px：主要页面的视口内布局回归。
- `tests/ui-polish.spec.ts`：学习入口、课程 URL／IME／清空、复盘返回、抽屉焦点、实验可达性、剪贴板拒绝、RTOS 配置与导出、键盘标签。
- 原有浏览器编译、课程／专题／搜索、Mermaid／PlantUML、RTOS 与内存回放用例一起回归。
- TypeScript／生产构建、课程结构、迁移校验、设计上下文 lint 与严格静态 UI 审计。

截图与交互检查用于验证本轮修改，不等同于完整的 WCAG 认证。实体手机、多浏览器及辅助技术的
进一步验证仍可按产品支持范围继续补充。源码中的 C++ 示例整改不属于本轮 UI 修改。
