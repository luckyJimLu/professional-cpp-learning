# 历史练习迁移清单

返回 [内容总索引](content-map.md)。本清单按已提交源码核对，区分“主 Lab 可运行”与“修复题有独立 starter”。不把工作区尚未提交的文件计入已发布成果。

## 基线

- Day 1–55 均有每日 `main.cpp`。
- 已入库的独立每日练习位于 Day 53、54、55；并不表示早期每道修改题均有独立文件。
- 本轮贯穿实验位于顶层 `examples/`，不改变课程编号，不替代后续每日发布。

## 每个迁移项的完成定义

1. 阅读原题，确认是代码修改任务，而不是纯知识问答。
2. 保存能独立编译、能安全运行的 starter；用文字说明哪项契约尚未满足。
3. 提供成功与失败输入、可观察结果及推荐解。参考解必须满足与题目一致的行为矩阵。
4. 不通过删除断言或放宽错误判断完成练习，不依赖隐藏头文件或 IDE 状态。
5. 同步修改对应课程的实验链接、预期结果和答案。使用现有 `exercise-XX.cpp` 命名规范。

逐 Day 补齐时才将对应项改为已完成。不能根据目录中有 `main.cpp` 推断存在所有修复练习。
