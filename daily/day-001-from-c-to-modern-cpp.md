## ② 昨日复习 · 5 分钟

以下是针对这三个问题的详细说明：

**1. 程序从哪里开始执行？**
在代码层面，程序从 `main()` 函数开始执行。

- **函数形式与参数**：`main()` 的返回类型为 `int`，用来表示程序的执行状态结果。它可以不带参数，也可以接收两个参数：`int main(int argc, char** argv)`（或 `char* argv[]`），其中 `argc` 表示传入程序的参数数量，`argv` 包含这些具体参数（真正的命令行参数从索引 `1` 开始）。

- **底层启动流程**：在实际进入程序员编写的 `main()` 之前，操作系统内核与语言运行时库会先执行底层的初始化调用。例如在 Windows 环境下（以 Visual C++ 为例），调用栈最底层始于内核函数（如 `ntdll!RtlUserThreadStart` 和 `KERNEL32!BaseThreadInitThunk`），随后进入 C/C++ 运行时启动函数（如 `mainCRTStartup` -> `__scrt_common_main` -> `invoke_main`），最终才正式调用代码中的 `main()` 函数。

**2. 头文件声明与源文件定义有什么区别？**
将接口（头文件 `.h`）与实现（源文件 `.cpp`）分离是组织代码的核心规范，两者的本质区别在于**向编译器提供的信息不同**以及**对编译和链接规则的影响不同**：

- **头文件中的“声明”（Declaration）**：

  - **作用**：声明通常放在头文件（`.h`）中，作为子系统或代码块的接口。它只告诉编译器某个名称的实体（如函数、变量、类）存在。对于函数而言，声明（也称函数原型或函数头）仅指定如何调用该函数（即函数名、参数数量与类型、返回类型），而不包含背后的实现代码。

  - **规则**：所有定义本身也是声明，但并非所有声明都是定义。在多个不同的文件中编写（或通过 `#include` 引入）同一个函数的原型声明是完全合法的。为了防止同一个转换单元内多次包含同一头文件导致重复定义，头文件通常需要配合包含卫哨（`#ifndef` / `#define` / `#endif`）或 `#pragma once` 使用。

- **源文件中的“定义”（Definition）**：

  - **作用**：定义通常放在源文件（`.cpp`）中。它不仅告诉编译器某个实体存在，还提供了该实体的完整具体实现（例如函数的实际执行代码体）。

  - **单一定义规则（ODR）与编译效率**：根据单一定义规则（ODR），整个程序中非内联（non-inline）函数和非内联变量只能有**唯一一个定义**。将具体定义放在源文件（`.cpp`）中可以显著缩短编译时间：如果把实现放在头文件里，哪怕只修改一行注释，所有包含该头文件的源文件都必须重新编译；而放在源文件中时，只要不改动头文件接口，修改实现后只需单独重新编译该源文件即可，随后由链接器（Linker）将各个独立编译生成的目标文件（Object files）链接成最终的可执行文件。

**3. 返回值如何传给调用者？**
函数将结果或状态传回给调用者（Caller）主要有以下几种方式与机制：

- **通过 `return` 语句向操作系统返回（针对 `main()` 函数）**：
  从 `main()` 函数返回会将控制权交还给操作系统，其返回的 `int` 值用于向操作系统通报执行状态。通常返回 `0`（或 `<cstdlib>` 中的 `EXIT_SUCCESS`）表示程序正常执行且无错误，返回非零值则表示发生了错误。如果在 `main()` 中省略了 `return` 语句，编译器会自动隐式补上一句 `return 0;`。此外，也可以直接调用 `_Exit()` 或 `exit()` 将整型状态码直接传回给操作系统并终止程序。

- **按值返回（Return by Value）**：
  对于普通函数（例如 `int addNumbers(int a, int b) { return a + b; }`），使用 `return` 语句可将计算结果传回给调用者并初始化接收变量（如 `int sum { addNumbers(5, 3) };`）。按值返回的结果是一个临时右值（rvalue）。当按值返回复杂对象时，推荐直接按值返回而非使用输出参数，因为现代编译器能够利用临时对象拷贝构造函数或自动应用移动语义（Move Semantics）来高效传递返回值。

- **按引用返回（Return by Reference）**：
  函数可以返回引用（如 `Type&`），若返回的是非 `const` 引用，则调用结果是一个左值（lvalue），可以直接放在赋值号左侧被继续赋值（常见于重载 `=`、`+=` 等运算符）。**注意**：绝不能返回指向函数内部局部栈变量的引用，因为局部变量在函数结束时就会被销毁，返回的引用必须指向函数结束后依然存活的变量。

- **通过输出参数（Output Parameters）与多值返回机制传递**：

  - **C 风格输出参数**：在 C 风格函数中，返回值本身常被用来传递整型错误码（`errorcode`）以指示函数是否执行成功，而真正需要返回的数据则通过指针或引用类型的“输出参数”（如传入二级指针 `int** data` 并在函数内解引用赋值 `*data = ...`，或传入引用参数 `Record& record` 进行修改）传回给调用者。

  - **现代多值封装**：因为函数只能有一个返回类型，若既要返回值又要返回错误码（或多个值），除了使用引用输出参数或特殊返回值（如 `nullptr`）外，还可以将它们打包进自定义的 `struct`/`class`、`std::pair`、`std::tuple` 或 `std::expected`（C++23）中，作为单一返回值传给调用者。

定义三个固定信号值，计算总和并输出。先把一个元素从 5 改成 6，并同步更新断言，确认总和变为 13；再将三个元素都改成 0，验证总和为 0。这里数组长度是函数参数类型的一部分，本课不要求改变长度。

完整源码：[main.cpp](../examples/day-001/main.cpp)。

```cpp
#include <array>
#include <cassert>
#include <iostream>
namespace modem {
int Sum(const std::array<int, 3>& signals) {
  int total{0};
  for (const int signal : signals) {
    total += signal;
  }
  return total;
}
}  // namespace modem
int main() {
  const std::array<int, 3> signals{3, 4, 5};
  const int total = modem::Sum(signals);
  assert(total == 12);
  std::cout << "signal sum=" << total << '\n';
}
```
